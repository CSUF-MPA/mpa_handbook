Accessibility Statement

Last updated: July 11, 2026

Commitment to Accessibility

California State University, Fullerton (CSUF) is committed to ensuring digital accessibility for all users, including those with disabilities. The MPA Student Handbook is designed to be accessible to everyone, regardless of their technology or abilities.

Standards and Compliance

This website aims to conform to the Web Content Accessibility Guidelines (WCAG) 2.2 (opens in new tab) Level AA. We continuously review and improve accessibility features.

Conformance Level

WCAG 2.2 Level AA — This means our content is accessible to most users with disabilities, including those who use:

  • Screen readers
  • Screen magnification software
  • Keyboard-only navigation
  • Voice recognition software

Accessibility Testing

This website is audited against WCAG 2.2 Level AA. The most recent audit was completed in July 2026 and covered all pages in both light and dark color themes.

Audit Coverage

  • Automated scanning: axe-core (WCAG 2.0/2.1/2.2 A and AA rules) and Lighthouse, run in both color themes
  • Keyboard navigation: Tab order, arrow-key patterns for tabs, skip links, focus visibility, and Escape handling
  • Reflow and magnification: Verified no horizontal scrolling at 320px viewport width (equivalent to 400% zoom)
  • Color contrast: All text and interactive states, including hover and focus, in both themes
  • Reduced motion: Animations and smooth scrolling respect prefers-reduced-motion

Assistive Technology Testing

Markup and ARIA patterns are built and reviewed for screen reader compatibility (NVDA, JAWS, VoiceOver), and manual screen reader testing is part of our ongoing review cycle.

Accessibility Features

  • Keyboard navigability: All interactive elements are accessible via keyboard
  • Screen reader compatibility: Proper ARIA labels, roles, and semantic HTML
  • High-contrast text: Minimum 4.5:1 contrast ratio for all text
  • Responsive design: Works on all screen sizes and orientations
  • Focus indicators: Visible focus states for all interactive elements
  • Alt text: Descriptive alternative text for all images
  • Heading structure: Logical heading hierarchy for easy navigation

Known Limitations

Despite our best efforts, some content may not be fully accessible. We are working to address these issues:

  • Some PDF documents may not be fully accessible (working on remediation)
  • Third-party embedded content may have varying accessibility
